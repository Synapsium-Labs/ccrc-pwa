# CodeQL as an advanced setup

- **D-7744 (2026-11-02)** — CodeQL moves from GitHub's default setup to an advanced setup (`.github/workflows/codeql.yml`): the same languages, query suite and runner, analysed on every pull request to main, once a day on main and on demand, with no push trigger and no merge-queue trigger; the daily run then deletes every overlay-base database in the Actions cache but the newest of each language. Measured 2026-10-30 to 11-02 (3.67 days): default setup's push-to-main analyses took 3,522 runner minutes (about 900 a day, a full javascript-typescript analysis of about 29 minutes each) and its overlay-base databases held 10.5 GB of the repository's 12.07 GB Actions cache (limit 10 GB). No ruleset or branch protection requires a CodeQL check or code-scanning results, so neither trigger gated a merge. The merge queue is left out because outside a pull request the action analyses without an overlay, so each queue group would cost a full analysis and gate nothing.
