- 180 s, late answer wins (Tasks 4, 6, 16);

The route's existence is the capability, and the version gate lives on the server (spec §6.9). So any mover in any order is safe, and this plan does not wait for working-state Task 9b.

## Global constraints

`CLAUDE.md` is the authority. This is its working subset for this plan.

- **Public repository.** Fixtures use neutral names: session ids `lane-a-project-a` and `project-a-quiet-basin` (child), `project-a-calm-mesa` (parent; an operator-created session with no `.child`), `project-a-still-cove` (a second child of the same project, for another-leaf rows), `project-a-open-dune` (a second operator-created session of the same project, no `.child`, for the not-a-child rows), `project-b-far-ridge` (a session in another project), wrappers `lane-a`/`lane-b`, agent ids such as `a0000000000000001`. No hostnames, accounts, project names, absolute home or scratch paths, emails, or anything read from a transcript. Guard-corpus commands are written for the corpus, never copied from a fleet transcript. A test signing key is generated in the test, never committed.
- **Hook payload fixtures copy a committed real shape.** A PreToolUse payload copies the key set of the PreToolUse events in `server/test/fixtures/delegation/2.1.280/agent-plain.json` (main: `session_id`, `transcript_path`, `cwd`, `prompt_id`, `permission_mode`, `effort`, `hook_event_name`, `tool_name`, `tool_input`, `tool_use_id`; a subagent's adds `agent_id`, `agent_type`). **No committed capture has a PermissionRequest yet.** Until Task 13 produces one (`server/test/fixtures/delegation/2.1.302/permission-main.json` and, if reproduced, `permission-subagent.json`, in the existing capture format), a PermissionRequest fixture is the PreToolUse key set with `tool_use_id` removed and `permission_suggestions` added, marked DERIVED with its source ([B]). Never bare `npx vitest`, never the full server suite. Typecheck with `./node_modules/.bin/tsc --noEmit -p .` in `server/` and `pwa/`.
