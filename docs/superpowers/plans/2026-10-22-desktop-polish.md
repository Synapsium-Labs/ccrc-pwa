## Review focus (the failure modes most likely to bite)

1. **Pane text sneaking back.** A fallback that reaches for `Dialog.title`, `body`, `raw` or a scraped label "just for this case" on an AskUserQuestion. `askSource` is the wall; review every branch that renders without calling it, including the review screen and the tab strip.
2. **A second envelope source with its own staleness.** T1a keeps the envelope on the session stream only, and only while the pane's menu corresponds to the pending call. A change that widens `HOOKSTATE_FRESH_MS`, or keeps aged envelopes in the fleet card, the push body, the hold or `answerAsk`'s read, widens the key-based answer gate. Rejected.
3. **A key on the page answering a question.** Today the modal makes `useAskKeys` own a key whose target is the page body, and makes `useEscapeInterrupt` stand down. Inline (T1c) there is no open dialog: a digit or arrow pressed with nothing focused, or an Escape from the page or the transcript on a busy session, must not reach the pane. Inline keys act only inside the surface; the interrupt stands down while an inline ask is mounted.
4. **The composer moving.** The inline card is a new keyed sibling; the composer's key and order never change (D-5466). `skin-switch.test.tsx` keeps its typed text across a skin switch with an inline ask up.
5. **Focus theft.** `useAskKeys`' fine-pointer focus effect pulls focus into the surface on open; inline it must not.
6. **One instance per width.** At the desk the ask is inline and no `Sheet` is mounted; on a phone the sheet and no card. One test per width class counts both.
7. **A count that counts for itself.** T2d's badges and T3a's chips each read one shared function; a door or chip that filters on its own disagrees with the fleet.
8. **"Unmeasured" read as "zero" or "clean".** A lane never read prints "no reading", never 0% (T2c); a badge before its first frame prints nothing (T2d); a stream that could not resolve its session sends no `ask_cleared` it did not measure (T1b's `none`); a send whose Enter reply was lost reads the box before it answers (B1).
9. **A door removed with its word.** The "no pool" chip is the only pool door (T3a); Mark all seen is the only ack door (T3a); the update banner's actions live on in Settings (T2a). A word may change; a door may not vanish.
10. **Visibility the parity test cannot see.** T3b's hover-revealed ⋯ stays mounted and focusable (opacity, never `display` or `visibility`), so S17's door walk still counts it under hover.
11. **A routing line that claims what it cannot measure.** T3d says "asked <class>" only where the readback vocabulary can see the lane's model ids, and an absent provider is not measurable.
12. **A send that types twice.** B1 and B2 press Enter only on text proved to be ours, read whole; a human's draft with the same prefix is still refused, and a resume over an empty box never retypes.
13. **A frozen file edited early.** T2a, T2b and T2d before #1116 merges.
