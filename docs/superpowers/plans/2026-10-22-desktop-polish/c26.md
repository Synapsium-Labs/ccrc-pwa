## Departures

- `bounded-darwin-errno-inferred`: the E9 cause is read from the evidence, not seen in a Darwin stack. The batch ended in
  0.4 s, began no row and wrote nothing to stderr, and its rc and signal were never printed. Three silent early ends fit:
  `BOUNDED`'s 125 and 127, and the batch's bash ended by a signal (a status of null, which the 11-11 log could not rule
  out). A spawn error would have no stderr string at all, and a fork or `source` failure prints, or exits 90 to 92, which
  the runner throws on. Only the FIFO case's silent 125 (the daily run of 2026-11-09) is seen. Which side's `setpgid`
  failed, and with which errno, is not measured: XNU's source allows EPERM on the parent's side. The fix covers a failure
  on either side once the group exists; a child whose own call fails before the group exists still exits 125, now with
  its reason. If the cause was none of these, the 125 or 127 prints its reason and the runner's message prints the
  batch's rc and signal, so the next red names its cause.
- `siwc-shipped-listener`: the brief names the test's loopback fakes; the shipped tool's own sign-in listener had the same
  35 s bind, so it is fixed too, under the brief's rule that shipped code wrong on Darwin is fixed in the shipped code.
