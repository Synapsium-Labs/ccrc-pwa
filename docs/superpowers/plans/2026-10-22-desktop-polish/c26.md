## Departures

- `bounded-darwin-errno-inferred`: the E9 cause is read from the evidence, not seen in a Darwin stack. The batch ended in
  0.4 s, began no row and wrote nothing to stderr, and the only silent early exits on that path are `BOUNDED`'s 125 and 127
  (a spawn error would have no stderr string at all; a fork or `source` failure prints, or exits 90 to 92, which the runner
  throws on). The same silent 125 is on record in another file on macOS. Which side's `setpgid` failed, and with which
  errno, is not measured: XNU's source allows EPERM on the parent's side. The fix holds whichever side it was, and if it
  was neither, the 125 or 127 now prints its reason and the runner's message prints the batch's rc and signal, so the
  next red names its cause. The macOS dispatch named in the wave-done is the measurement of this task's fix.
- `siwc-shipped-listener`: the brief names the test's loopback fakes; the shipped tool's own sign-in listener had the same
  35 s bind, so it is fixed too, under the brief's rule that shipped code wrong on Darwin is fixed in the shipped code.
