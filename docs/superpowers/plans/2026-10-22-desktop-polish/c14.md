## Departures

- **`c14-spaced-dash-ends-a-sentence`** (item 2). The ruling takes a grammar only if all ten shapes hold, and one of them
  is "#651 merged — is it out?", which keeps its label only if a spaced dash ends a sentence. So it does, and that has a
  cost: a question split by a spaced dash reads its first half alone, so "Is CI green — or red?" keeps a green label. The
  cost is pinned as a row ("a spaced dash splits a question as well") so a later change is deliberate. An unspaced dash
  ends nothing ("Is CI green—or red?" gives no label).
- **`c14-unclosed-aside-hides-its-ends`** (item 2). An aside left open hides every sentence end after it, so
  "CI green (see the log? on main." keeps its label where the old grammar withheld it. It is the same rule as "#651 merged
  (why?) and shipped.", with no closing bracket to end the aside.
- **`c14-null-glyph-retires-two-empty-rules`** (item 11). The primitive change made two rules match nothing:
  `.ref-tab > [aria-hidden='true']:empty` (`refined.css`) and `.update-indicator-door > [aria-hidden='true']:empty`
  (`fleet.css`). They are removed, and `fleet.css`'s comment no longer says `Door` always draws the span. Neither file is in
  the item's row; both were claimed first.
- **`c14-pins-in-their-siblings-files`** (items 5, 7, 11, 12). A pin sits where its siblings live, in files the items'
  rows do not name: `chat-links.test.tsx` (item 5), `runs-arrival.test.tsx` (item 7), `primitives.test.tsx` (item 11),
  and `refined-shell.test.tsx` and `phone-bar.test.tsx` (item 12, "in all three skins"). Each was claimed first.
- **`c14-file-ms-from-a-queue-run`** (item 10, A7). `FILE_MS` is refreshed from the merge queue's green run 42431228712
  (2026-11-08), because the runs on `main` since then are the three-hourly refreshes, which run no browser suite. Two
