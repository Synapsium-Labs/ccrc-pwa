## Departures

- `joined-only-adds`: M5 says "the same union". Read literally, a joined address would give a bare name a number of its own,
  and the first fuzz run of this round measured what that does: 167 names went from a rule-3 home link to another repository
  and 115 from text to a link, all to a repository the joined text names, none toward text, and F2's `gh pr checks` repro
  opened owner-c where the brief asks for text at both split points. So what only the joined reading finds adds a repository
  to `named`, and to a number or commit the raw reading already gives a repository, and gives none of its own. With it every
  M5 change fails toward text.
- `raw-value-skips-continuation`: the raw reading skips a continuation where a flag's value starts (after the flag, after `=`,
  or in the spaces between), as the shell reads it, so a continued command's value still reads in the raw text and P1's
  correct links stay. Inside a value (`org-a/projec\` LF `t-a`) the raw reading keeps the backslash and names a repository the
  chat cannot tell, so such a value gives text, as on `main` before C23.
- `glued-tail-after-quote-only`: F4 is read as asked, a tail after a closing quote. An unquoted value still ends at a quote,
  and so does a tail: the net reads flags inside quoted bodies, where the next quote closes the body
  (`--body "--repo=owner-b/repo-b"` must read `owner-b/repo-b`, the L3-1 row). A first version that glued quoted parts after
  an unquoted value turned that row and C22's quoted-run row to text.
- `prose-quote-between-letters`: the join's quote reading is the shell's except for prose: a quote between two letters or
  digits opens nothing, and a quote whose span meets a line break no backslash stands before opens nothing either, so a prose
  apostrophe never keeps a continuation on a later line unjoined.
- `commands-read-raw-only`: M5's `gh`-word reader is read as the gate that makes the net run, which reads the joined text
  too. Reading `gh` commands from the joined text is not small: their claims stand in the raw text, so a second command
  pass would need its words mapped back and merged with the first pass's claims in message order, and the command reader
  already deletes every continuation except one that splits the `gh` word itself (review 1800 F3). That shape now gives text
  where it opened home: the joined `gh` word makes the net run, and the net names the flag.

## Recorded

- **F3, CRLF.** As C23 ruled, a backslash then CRLF is a continuation here; bash reads a backslash then CR as an escaped CR,
  and the CR stays. Unchanged.
- **F3, the shell's reading over a quote-blind join (6 names in the fuzz).** `'-` `\` LF `R' owner-c/repo-c` is the word
  `-\`, LF, `R` to the shell, not a flag, so the repository after it is a positional, which R15 does not read: a bare name
  beside it now opens home where the quote-blind join (C23) read a flag with an unreadable value and gave text. Neither the
  raw nor the shell's reading names another repository there.
- **F4, the glued tail (2 names in the fuzz).** `cp -R "Owner-B/Repo-B"-x` and `gh pr view 12 -R 'owner-b/repo-b'-x` now
  name the same repository, so #12 opens `owner-b/repo-b-x`, which both flags name, where `main` read the `cp` value as
  `Owner-B/Repo-B` and gave text.
- **C23's 353 "text to home by rule 3" names.** Most were a value split by a continuation inside it, which the raw reading
  names as a repository the chat cannot tell, so they give text again, as on `main` before C23. A continuation between a
  flag and its value still reads as a space (`raw-value-skips-continuation`).
- **The address readers' older gap (F2).** An address split anywhere else is read joined too, so it adds its repository to a
  number or commit another source names: `gh pr view 12 -R owner-b/repo-b; curl https://api.github.com/repos/owner-c/re` `\`
  LF `po-c/pulls/12; #12` gives text where it opened owner-b. Alone, a split address names its repository but gives a bare
  name nothing, so the bare name is text in a home session (`joined-only-adds`).
- **The join's quote reading, residuals.** Double quotes are not tracked, so a single quote inside them opens a span
  (`"a 'b` `\` LF `c' d"` keeps that continuation, where bash joins it); and a prose quote at a word start (`'90s`) pairs with
  a later quote on the same logical line. Both keep a continuation unjoined in that span, which only removes a find the
  joined reading would add, and the raw reading still reads.
- **M2 (corrects `c23.md`'s carried-gap bullet).** The carried commit page forms (`blob/`, `tree/`, `compare/`,
  `pull/N/commits/`, `raw.githubusercontent`, `owner/repo@sha`) can name a SHA that three readers name elsewhere, not two: a
  commit page, a `gh api` commits path, and, since C23's fix round 2, an `api.github.com` commits address
  (`https://api.github.com/repos/owner-b/repo-b/commits/1234567abc; https://github.com/owner-c/repo-c/blob/1234567abc/x.ts and
  1234567abc` opens owner-b). Still carried, unchanged.
- **M3 (corrects `c23.md`'s N04 reason).** The map read one character late is equivalent for two reasons together: the raw
  character before every claim's start is whitespace, so a find never starts one character before a claim; and the character
  that closes a claim can never be a find's second character, since a continuation there would have joined the word. ("A find
  always starts a word" is not literally true: `-R=o/r,-R=x/y` holds two finds.)
- **M4 (residual).** A flag spelling split by quotes (`--re'po'`, `-'R'`) is invisible to the net, as on `main`.
- **M7.** It concerns the merged #2648's PR body, not this task.
- **M8 (corrects `c23.md:55`).** "Repro 1 (three shapes, in a home and a cross session)": only shape 1a ran in both; 1b and
  1c ran in a home session only. Both are pinned in a cross session now.
- **M10.** C23's head commit's `Ledger-Edit:` trailer named the plan section and D-8279 only, though that PR also edited

## Differential fuzz, this task against main

**What it measures.** Every PR and commit name of a random `gh` message, resolved by `refHref` in a **home session** (home
repository `org-a/project-a`, no run elsewhere) by `main`'s reader (`544060e34`, C23 merged) and by this branch's. The unit
of every count is a **name**, unless it says messages. A changed name that links home is also resolved in a session that
claims a run elsewhere, where rule 3 cannot open home: a link that stays is attributed by the message (rule 1 or 2).

**The generator** is C23's (its appendix) with this round's additions: a word character glued before a continuation that
precedes a repository flag or a `repos/` path (F1); a quoted value with a word glued after its closing quote, and one split
inside single quotes, `$'..'` or double quotes (F3, F4), as a `gh` flag's value and as `cp -R`'s; `api.github.com`, pull and
commit addresses split at a random place, at `host|/` and at `/|repos` first (F2); a split `GH_REPO`; a split `repos/`
word after a word.

**The checks**, each on the raw text and the text as bash reads it (outside quotes and inside double quotes an unescaped
backslash-newline is deleted; inside `'..'` and `$'..'` it is kept; written apart from the reader):
- *Two repositories:* the generator records, as it writes them, the repository every plain source names a number or a SHA
  in (C23's list, plus a `gh pr view <n> -R 'o/r'x` command, which names `o/rx`). Every linked name, changed or not, whose
  message names it in two or more repositories by those forms is counted; a source the backtick wrap rewrote (its line
  breaks made spaces) is no longer in the message and counts for nothing. One named twice only through a carried form is
  counted apart.
- *No reading names it:* every link to a repository other than home must be a token of the raw text, of bash's reading, or of
  the quote-blind join, with or without quotes.
- *New home link where another repository is named:* a changed name that links home by rule 3 is counted where the raw text
  or bash's reading names any repository but home where R15 reads one (a repository flag's value, continuations before it
  skipped, a `github.com` or `repos/` address, `GH_REPO`, before `#n`), read generically, so a glued or cut value counts.
- *One repository to another:* every change from one link to a different link.

// Usage: node fuzz24.mjs <tip bundle> <base bundle> <seed> <messages> [examples per class]
// Each bundle exports links(text) and linksCross(text): [name, href|null][] for every PR and commit name, resolved by
// refHref in a home session (org-a/project-a) and in one that claims a run elsewhere (rule 3 never opens home there).

    `cp -R ${quotedValue(pick(repos))} /y`, `G${pick(CONT)}H_REPO=${pick(repos)}`, `see${pick(CONT)}repos/${pick(repos)}/pulls/12`]);
};

const message = () => {
  truth = [];
  const parts = many(() => { const r = rnd(); return r < 0.5 ? command() : r < 0.75 ? sources() : bare(); }, 1, 5);
  parts.push(bare());
  let text = parts.map((p, i) => (i === 0 ? p : joiner() + p)).join('');
  if (rnd() < 0.15) text = '```\n' + text + '\n```\n' + bare();
  if (rnd() < 0.1) text = '`' + text.replace(/\n/g, ' ') + '`';
  return text;
};

/** The message as bash reads it (C24): outside quotes a backslash escapes the next character and an unescaped
 *  backslash-newline is deleted; inside double quotes the same; inside '..' nothing is escaped or deleted; inside $'..' a
 *  backslash escapes and nothing is deleted. Written apart from the reader: a quote is a quote wherever it stands. */
const bashJoined = (text) => {
  let out = '';
  let mode = 'out';
  for (let i = 0; i < text.length; i += 1) {
    const c = text[i];
    const nl = text[i + 1] === '\n' ? 1 : text[i + 1] === '\r' && text[i + 2] === '\n' ? 2 : 0;
    if (mode === 'single') { out += c; if (c === "'") mode = 'out'; continue; }
    if (mode === 'ansi') { out += c; if (c === '\\') { out += text[i + 1] ?? ''; i += 1; } else if (c === "'") mode = 'out'; continue; }
    if (c === '\\') {
      if (nl) { i += nl; continue; }
      out += c + (text[i + 1] ?? ''); i += 1; continue;
    }
    out += c;
    if (mode === 'double') { if (c === '"') mode = 'out'; continue; }
    if (c === '"') mode = 'double';
    else if (c === "'") mode = text[i - 1] === '$' ? 'ansi' : 'single';
  }
  return out;
};
/** The shell's join with no quotes at all (C23's oracle), a second reading the reader may take where a quote is prose. */
const plainJoined = (text) => text.replace(/(\\+)(\r?\n)/g, (m, run, nl) => (run.length % 2 === 1 ? run.slice(1) : m));
const readings = (text) => [text, bashJoined(text), plainJoined(text)].flatMap((t) => [t, t.replace(/['"]/g, '')]);
/** Whether `slug` (owner/repo) stands as a token of `text`, in any case. */

  const esc = slug.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  return new RegExp(`(?:(?<![\\w.-])|(?<=-[A-Za-z]*R=?))${esc}(?![\\w-]|\\.\\w)`, 'i').test(text);
};
/** Every repository `text` names where R15 reads one, generically (C24, so a glued or truncated value counts): a repository
 *  flag's value (spaces, tabs and continuations skipped before it), a github.com or repos/ address, GH_REPO, or before `#n`.
 *  Lower case, trailing dots trimmed. */

  const out = [];
  const val = '([^\\s`;&|,()<>]+)';
  for (const m of text.matchAll(new RegExp(`(?<![\\w-])(?:-[A-Za-z]*?R|--repo)(?:[ \\t=]|\\\\\\r?\\n)*${val}`, 'g'))) out.push(m[1]);
  for (const m of text.matchAll(new RegExp(`(?:github\\.com[/:]|repos/)([\\w.-]+/[\\w.-]+)`, 'gi'))) out.push(m[1]);
  for (const m of text.matchAll(new RegExp(`GH_REPO(?:=|:[ \\t]*)${val}`, 'g'))) out.push(m[1]);
  for (const m of text.matchAll(/(?<![\w.\/-])([\w.-]+\/[\w.-]+)#\d/g)) out.push(m[1]);
  return out.map((v) => v.replace(/^['"]|['"]$/g, '').toLowerCase().replace(/\.+$/, ''));
};

  }

};
