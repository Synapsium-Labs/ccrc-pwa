## Differential fuzz, this task against main

**What it measures.** Every PR and commit name of a random `gh` message, resolved by `refHref` in a **home session** (home
repository `org-a/project-a`, no run elsewhere) by main's reader (`514324939`) and by this branch's. The unit of every count
is a **name**, unless it says messages. A changed name that links home is also resolved in a session that claims a run
elsewhere, where rule 3 cannot open home: a link that stays is attributed by the message (rule 1 or 2), and one that goes is
a rule-3 home link, which is then checked against the message (below).

**Three oracles, all on the message as the shell reads it** (every unescaped continuation deleted: an odd run of backslashes
before a line break loses one backslash and the line break; an even run is left):
- *Token:* a changed name's linked repository stands in the read message as a token, in any case, after a word start or a
  glued repository flag (`-Rowner-b/repo-b`). A token formed only once the shell removes the quotes around a word's half
  (`'owner-b/repo'`, a continuation, then `-b`) is counted apart.
- *Two repositories (review 1800's check):* the generator records, as it writes them, the repository every plain source
  names a number or a SHA in: a qualified name, a pull or commit page, an API pulls or commits address (with sub-paths and
  `git/commits`), a `gh api` pulls or commits path (with sub-paths), a `gh pr view <n> -R o/r` command, and the carried forms
  (`blob/`, `tree/`, `compare/`, `pull/N/commits/`, `owner/repo@sha`). Every **linked** name, changed or not, whose message
  names it in two or more repositories by those forms is counted; one named twice only through a carried form is counted
  apart. A SHA counts for a commit name where one starts the other.
- *Rule-3 home:* a rule-3 home link must stand in a message that names no repository but home in any form R15 reads (a
  repository flag's value, a `github.com` or `repos/` address, `GH_REPO`, or before `#n`); one where another repository is
  named only by a carried `owner/repo@sha` is counted apart.

**The generator** (appendix) writes `gh` words in every case and `.exe`; the `pr`, `issue`, `api` and other groups; numbers and
`#n`; every repository flag spelling (spaced, glued, `=`, runs, quoted, quoted with a continuation after it); value flags with
`GH`, `gh` and an even backslash run as values; quoted bodies; `api` paths to pulls, issues, commits (either case, sub-paths,
`git/commits`, a 6-hex sha); a continuation (LF or CRLF) between words, glued inside a word at a random place (so inside a
flag's spelling too), and as an even or odd backslash run; the sources above, and `cp -R`, `chmod -R`, `GH_REPO` and cut

  these apart (106 names, and 3 home links where `owner/repo@sha` is the only other naming).
- **Review 1795 F3 (no change).** `gh` followed by a continuation is `ghapi` to the shell, not a command, and the reader agrees:
  `gh`, a continuation, then `api repos/"owner-c/repo-c"/pulls/13 and #13` opens home on main and here (the net's path word
  does not read a quoted path).

## Departures

- `numberless-read-flags-too`: item 1 is read literally. A numberless command claims none of its repository flags, the ones
  it read as well as the ones it lost, because P2's shape (`-s 12 -R o/r` in a merge command) reads its flag and has no
  number. The cost is the first "link to text" row above.
- `api-path-claim-unchanged`: a `gh api` path is no repository flag, so a path its command read stays that command's
  whether or not it gives a number (pinned; A17). So review 1795's shape (b), `gh api repos/owner-b/repo-b/pulls --jq '.[] |
  select(.number==12)'` beside an owner-c pull address and `#12`, opens owner-c: the path gives no number, as ruled (pinned).
- `cut-number-always-unknown`: a cut command gives its number, and its commit, to an unknown repository even where it names
  none, unlike a command voided by an open quote, which is decided as if absent when it names none (C20's review 1766 F1
  stands).
- `continuation-not-in-the-net`: retired by fix round 2 (review 1800 A). The net reads the joined text, so it reads a split
  flag spelling and a split value as the command reader does. It said the net "only adds a repository the chat cannot tell,
  or misses one in another program's flag, as main does", which was too narrow: a numberless command's flag and a `gh api`
  command's flag were `gh`'s own, and repro 1 differed from main. What stays unread is a split `gh` word (F3 above).
- `one-commit-writer`: page addresses, `gh api` commits paths and the candidates all go through one writer, `atCommit`, so
  each (repository, SHA) pair is written once whatever names it.

## Appendix: the fuzz generator

`fuzz.mjs`, as run for fix round 2's table (Node 24, no dependencies; fix round 1's version wrote fewer forms and no ground
truth):

```js
// Differential fuzz of the chat's repository reader: main against this branch (Task C23, fix round 2).
// Usage: node fuzz.mjs <tip bundle> <base bundle> <seed> <messages> [examples per class]
// Each bundle exports links(text) and linksCross(text): [name, href|null][] for every PR and commit name, resolved by
// refHref in a home session (org-a/project-a) and in one that claims a run elsewhere (rule 3 never opens home there).
import { pathToFileURL } from 'node:url';
const [tipPath, basePath, seedArg, countArg, samplesArg] = process.argv.slice(2);
const tip = await import(pathToFileURL(tipPath).href);
const base = await import(pathToFileURL(basePath).href);
const seed = Number(seedArg ?? 1);
const count = Number(countArg ?? 20000);
const samples = Number(samplesArg ?? 3);

let s = seed >>> 0 || 1;
const rnd = () => { s ^= s << 13; s >>>= 0; s ^= s >>> 17; s ^= s << 5; s >>>= 0; return s / 4294967296; };
const pick = (a) => a[Math.floor(rnd() * a.length)];
const many = (f, lo, hi) => Array.from({ length: lo + Math.floor(rnd() * (hi - lo + 1)) }, f);

const HOME = 'org-a/project-a';
const repos = ['owner-b/repo-b', 'owner-c/repo-c', HOME, 'Owner-B/Repo-B', 'src/lib', 'a', 'owner-b/repo-b.', 'o/r.Then', 'o/r.12'];
const ghWord = ['gh', 'gh', 'gh', 'GH', 'Gh', 'gh.exe', 'GH.EXE'];
const groups = ['pr view', 'pr merge', 'pr list', 'pr comment', 'issue edit', 'issue view', 'pr checks', 'api', 'repo clone', 'run list'];
const nums = ['12', '12', '13', '#12', '40'];
const CONT = ['\\\n', '\\\r\n'];
/** A word with a continuation glued inside it at a random place (the shell joins the halves), or an even run (a line end). */
const split = (w) => {
  if (w.length < 2 || rnd() > 0.25) return w;
  const at = 1 + Math.floor(rnd() * (w.length - 1));
  return w.slice(0, at) + pick([...CONT, ...CONT, '\\\\\n', '\\\\\\\n']) + w.slice(at);
};
const repoFlag = () => split(pick([
  `-R ${pick(repos)}`, `--repo ${pick(repos)}`, `--repo=${pick(repos)}`, `-R=${pick(repos)}`, `-R${pick(repos)}`,
  `-sR ${pick(repos)}`, `-sdR ${pick(repos)}`, `-dR ${pick(repos)}`, `-wR ${pick(repos)}`, `'-R' ${pick(repos)}`,
  `-R \\\n${pick(repos)}`, '-R', `-R "${pick(repos)}"`, `-R '${pick(repos)}'${pick(CONT)}-x`,
]));
const otherFlag = () => split(pick([
  '-s', '-m', '-e', '-b', '-d', '-w', '--squash', '--web', '--json state', '-L5', '-XGET', '-X GET', '--title', '--body',
  `--title ${pick(['GH', 'gh', 'Gh', 'gh.exe', 'GH.EXE', '"GH"', 'fix', 'x\\\\'])}`, `--body "${pick(['--repo=', '-R ', 'see -R '])}${pick(repos)}"`,
  `--add-label ${pick(['bug', 'GH'])}`, '--list', '-q.title', '--jq .title', '-iXGET', '-f state=closed',
]));
const arg = () => {
  const r = rnd();
  if (r < 0.3) return repoFlag();
  if (r < 0.55) return otherFlag();
  if (r < 0.75) return pick(nums);
  if (r < 0.9) return split(`repos/${pick(repos)}/${pick(['pulls/12', 'pulls/13', 'commits/1234567abc', 'commits/1234567ABC', 'pulls',
    'commits/1234567abd/status', 'git/commits/1234567abc', 'commits/abc123'])}`);
  return pick(['now', 'then', 'and', pick(repos), '12', '\\']);
};
const sep = () => pick([' ', ' ', ' ', ' \\\n', ' \\\r\n', '\n', ' \\\\\n']);
const command = () => [pick(ghWord), pick(groups), ...many(arg, 0, 5)].map((w, i) => (i === 0 ? w : sep() + w)).join('');
/** What the message names, by construction: [name, repository key, carried], for the forms below whose meaning is plain. */
let truth = [];
/** Repositories every reader of GitHub names can tell (a refused or unknown one is never a source of truth). */
const good = ['owner-b/repo-b', 'owner-c/repo-c', HOME, 'Owner-B/Repo-B'];
const SHAS = ['1234567abc', '1234567abd'];
const says = (name, repo, carried = false) => { truth.push([name, repo.toLowerCase(), carried]); };
const sources = () => {
  const r = rnd();
  const repo = pick(good);
  const n = pick(['12', '13']);
  const sha = pick(SHAS);
  if (r < 0.1) { says(`#${n}`, repo); return `${repo}#${n}`; }
  if (r < 0.2) { says(`#${n}`, repo); return `https://github.com/${repo}/pull/${n}`; }
  if (r < 0.3) { says(sha, repo); return `https://github.com/${repo}/commit/${sha}`; }
  if (r < 0.37) { says(sha, repo); return `https://api.github.com/repos/${repo}/${pick(['commits', 'git/commits'])}/${sha}${pick(['', '/status', '/check-runs'])}`; }
  if (r < 0.42) { says(`#${n}`, repo); return `https://api.github.com/repos/${repo}/pulls/${n}`; }
  if (r < 0.49) { says(sha, repo); return `gh api repos/${repo}/commits/${sha}${pick(['', '/status', '/pulls'])}`; }
  if (r < 0.54) { says(`#${n}`, repo); return `gh pr view ${n} -R ${repo}`; }
  if (r < 0.62) {
    says(sha, repo, true);
    return pick([`https://github.com/${repo}/blob/${sha}/x.ts`, `https://github.com/${repo}/tree/${sha}`,
      `https://github.com/${repo}/compare/main...${sha}`, `https://github.com/${repo}/pull/9/commits/${sha}`, `${repo}@${sha}`]);
  }
  return pick([`cp -R ${pick(repos)} /x`, 'chmod -R 755 dist', 'GH_REPO=owner-b/repo-b', `GH_REPO: ${pick(repos)}`,
    `/repos/${pick(repos)}/pulls`, `-R ${pick(repos)}.-R=${pick(repos)}`, 'GH_TOKEN=x cp -R a b']);
};
const bare = () => pick(['#12', '#13', '#40', '1234567abc', '1234567abd', '1234567a', '#12 is merged', 'fixed in #12']);
const joiner = () => pick(['; ', '\n', ', then ', ' and ', '\r\n', '\n\n']);
const message = () => {
  truth = [];
  const parts = many(() => { const r = rnd(); return r < 0.5 ? command() : r < 0.75 ? sources() : bare(); }, 1, 5);
  parts.push(bare());
  let text = parts.map((p, i) => (i === 0 ? p : joiner() + p)).join('');
  if (rnd() < 0.15) text = '```\n' + text + '\n```\n' + bare();
  if (rnd() < 0.1) text = '`' + text.replace(/\n/g, ' ') + '`';
  return text;
};

/** The message as the shell reads it: each unescaped backslash-newline (an odd run of backslashes before it) deleted. */
const shellJoined = (text) => text.replace(/(\\+)(\r?\n)/g, (m, run, nl) => (run.length % 2 === 1 ? run.slice(1) : m));
/** Whether `slug` (owner/repo) stands as a token of `text`, in any case. */
const tokenOf = (text, slug) => {
  const esc = slug.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  return new RegExp(`(?:(?<![\\w.-])|(?<=-[A-Za-z]*R=?))${esc}(?![\\w-]|\\.\\w)`, 'i').test(text);
};
/** Whether `slug` stands in `text` where R15 reads a repository: a repository flag's value, a github.com or repos/ address,
 *  GH_REPO, or before `#n` or `@sha`. */
const namedAsRepo = (text, slug, carried) => {
  const esc = slug.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  return new RegExp(`(?:(?:-[A-Za-z]*R|--repo)[ \\t=]*['"]?|github\\.com[/:]|repos/|GH_REPO[=:][ \\t]*['"]?)${esc}(?![\\w-]|\\.\\w)|`
    + `(?<![\\w.-])${esc}(?:#\\d${carried ? '|@[0-9a-f]' : ''})`, 'i').test(text);
};
const slugOf = (href) => href.replace(/^https:\/\/github\.com\//, '').split('/').slice(0, 2).join('/');
const kind = (href) => (href === null ? 'text' : slugOf(href).toLowerCase() === HOME ? 'home' : 'other');

/** The repositories the message names `name` in by construction: a number by its `#n`; a SHA where one starts the other. */
const truthFor = (name, carried) => {
  const keys = new Set();
  for (const [n, repo, c] of truth) {
    if (!carried && c) continue;
    const hit = name.startsWith('#') ? n === name : !n.startsWith('#') && (n.startsWith(name) || name.startsWith(n));
    if (hit) keys.add(repo);
  }
  return keys;
};
let twoRepoLinks = 0;
let twoRepoCarried = 0;
const classes = new Map();
const note = (cls, text, b, t) => {
  const c = classes.get(cls) ?? { n: 0, ex: [] };
  c.n += 1;
  if (c.ex.length < samples) c.ex.push({ text, base: b, tip: t });
  classes.set(cls, c);
};
let names = 0;
let changedMessages = 0;
let withContinuation = 0;
for (let k = 0; k < count; k += 1) {
  const text = message();
  if (/\\\r?\n/.test(text)) withContinuation += 1;
  const b = base.links(text);
  const t = tip.links(text);
  if (b.length !== t.length) { note('name count differs', text, b, t); continue; }
  let diff = false;
  for (let i = 0; i < b.length; i += 1) {
    names += 1;
    const hb = b[i][1];
    const ht = t[i][1];
    if (ht !== null) {
      const name = t[i][0].startsWith('#') ? t[i][0] : t[i][0].toLowerCase();
      if (truthFor(name, false).size >= 2) { twoRepoLinks += 1; note('LINKED, NAMED IN TWO REPOSITORIES', text, b[i], t[i]); }
      else if (truthFor(name, true).size >= 2) { twoRepoCarried += 1; note('linked, named in two repositories by a carried form', text, b[i], t[i]); }
    }
    if ((hb ?? '').toLowerCase() === (ht ?? '').toLowerCase() && (hb === null) === (ht === null)) continue;
    diff = true;
    const kb = kind(hb);
    const kt = kind(ht);
    let cls = `${kb} -> ${kt}`;
    if (kt === 'home') {
      if (tip.linksCross(text)[i][1] === ht) cls += ' (attributed)';
      else {
        const read = shellJoined(text).replace(/['"]/g, '');
        const others = [...repos, ...good].filter((slug) => slug.toLowerCase() !== HOME);
        const other = others.some((slug) => namedAsRepo(read, slug, false));
        const carriedOnly = !other && others.some((slug) => namedAsRepo(read, slug, true));
        cls += other ? ' (FALLBACK HOME, THE MESSAGE NAMES ANOTHER REPOSITORY)'
          : carriedOnly ? ' (rule 3; another repository named only by a carried owner/repo@sha)'
            : ' (rule 3: the shell-read message names no repository but home)';
      }
    }
    if (kt !== 'text') {
      const joined = shellJoined(text);
      cls += tokenOf(joined, slugOf(ht)) ? ' [a token of the shell-joined message]'
        : tokenOf(joined.replace(/['"]/g, ''), slugOf(ht)) ? ' [a token once the shell removes its quotes]' : ' [NOT A TOKEN]';
    }
    note(cls, text, [b[i][0], hb], [t[i][0], ht]);
  }
  if (diff) changedMessages += 1;
}
console.log(JSON.stringify({ seed, messages: count, withContinuation, names, changedMessages, twoRepoLinks, twoRepoCarried,
  classesInNames: Object.fromEntries([...classes].map(([k, v]) => [k, v.n])) }));
for (const [k, v] of classes) {
  console.log(`\n== ${k} (${v.n})`);
  for (const e of v.ex) console.log(JSON.stringify(e));
}
```
