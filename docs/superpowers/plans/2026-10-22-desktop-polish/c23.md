## Differential fuzz, this task against main

**What it measures.** Every PR and commit name of a random `gh` message, resolved by `refHref` in a **home session** (home
repository `org-a/project-a`, no run elsewhere) by main's reader (`514324939`) and by this branch's. The unit of every count
is a **name**, unless it says messages. A changed name that links home is also resolved in a session that claims a run
elsewhere, where rule 3 cannot open home: a link that stays is attributed by the message (rule 1 or 2), one that goes is a
fallback home link. **The oracle is the shell's reading:** each changed name that turns into a link is checked against the
message with every unescaped continuation deleted (an odd run of backslashes before a line break loses one backslash and the
line break; an even run is left). Its linked repository must stand there as a token, in any case. A token the shell forms
only once it removes the quotes around a word's half (`'owner-b/repo'`, a continuation, then `-b`) is counted apart.

**The generator** (appendix) writes `gh` words in every case and `.exe`; the `pr`, `issue`, `api` and other groups; numbers and
`#n`; every repository flag spelling (spaced, glued, `=`, runs, quoted, quoted with a continuation after it); value flags with
`GH`, `gh` and an even backslash run as values; quoted bodies; `api` paths to pulls, issues and commits (either case); a
continuation (LF or CRLF) between words, glued inside a word at a random place, and as an even or odd backslash run; second
sources (qualified names, pull and commit pages, `cp -R`, `chmod -R`, `GH_REPO`, cut values); fences and backticks.

## What turns from a link to text

Each is a fail-safe cost of a ruling above:

- Item 1: a numberless command's flag is a candidate for every number, so `gh pr list -R owner-b/repo-b; gh pr view 13 -R
  owner-c/repo-c; #13` gives text where it opened owner-c. A flag naming the number's own repository leaves one
  (`… gh pr view 13 -R owner-b/repo-b; #13` opens owner-b).
- Item 3: `gh pr view 12 -R owner-b/repo-b --title GH and #12` opened owner-b on main and is text now (a flag read before the
  cut does not save the number), and `gh pr view 12 --title gh`, then `#12` on the next line, opened home on main and is text
  now. (Corrected by fix round 1, review 1795 L3a: this list named `gh pr view 12 --title GH -R owner-b/repo-b and #12`, which
  has been text on main since C22.)
- Item 6: a commit address beside an unrelated net flag in a `gh` message gives text
  (`https://github.com/owner-b/repo-b/commit/1234567abc; gh pr list; cp -R owner-c/repo-c /x; 1234567abc`).
- Item 7: a value cut at the next flag that named home no longer opens home (`gh pr list; -R org-a/project-a.-R=…; #12`).

## What turns from text to a link

- Item 2 (P1): a continued command's flag is its own, so `gh pr view --repo owner-b/repo-b \` then `12`, then `#12`, opens
  owner-b, as do C22's continuation rows (`gh pr view 12 \` then `--repo owner-b/repo-b`; `gh api \` then
  `repos/owner-b/repo-b/pulls/12`), which were text. Four existing pins changed from text to owner-b, each with a comment.
- Fix round 1, the join (F1, C3): a word split by a glued continuation reads whole, so `-R owner-b/repo`, a continuation, then
  `-b` opens owner-b/repo-b, and `-`, a continuation, then `R owner-b/repo-b` reads as the flag.
- Fix round 1, F2: a `gh api` commits path names its sha, so `gh api -XGET repos/owner-b/repo-b/commits/1234567abc and
  1234567abc` opens owner-b's commit, where it was text. One existing pin changed, with a comment.
- In the fuzz, every such link is a token of the message as the shell reads it.

## Departures

- `numberless-read-flags-too`: item 1 is read literally. A numberless command claims none of its repository flags, the ones
  it read as well as the ones it lost, because P2's shape (`-s 12 -R o/r` in a merge command) reads its flag and has no
  number. The cost is the first "link to text" row above.
- `api-path-claim-unchanged`: a `gh api` path is no repository flag, so a path its command read stays that command's
  whether or not it gives a number (pinned; A17). So review 1795's shape (b), `gh api repos/owner-b/repo-b/pulls --jq '.[] |
  select(.number==12)'` beside an owner-c pull address and `#12`, opens owner-c: the path gives no number, as ruled (pinned).
- `cut-number-always-unknown`: a cut command gives its number, and its commit, to an unknown repository even where it names
  none, unlike a command voided by an open quote, which is decided as if absent when it names none (C20's review 1766 F1
  stands).
- `continuation-not-in-the-net`: the net's value reader does not delete a continuation (`-R`, a space and a continuation,
  then `o/r`; or `-R owner-b/repo`, a continuation, then `-b`, names an unknown repository there), and its flag pattern does
  not read `-`, a continuation, then `R`. It only adds a repository the chat cannot tell, or misses one in another program's
  flag, as main does; the command reader reads the flag as its own.
- `one-commit-writer`: page addresses, `gh api` commits paths and the candidates all go through one writer, `atCommit`, so
  each (repository, SHA) pair is written once whatever names it.

## Appendix: the fuzz generator

`fuzz.mjs`, as run for the table above (Node 24, no dependencies):

```js
// Differential fuzz of the chat's repository reader: main against this branch (Task C23, fix round 1).
// Usage: node fuzz.mjs <tip bundle> <base bundle> <seed> <messages> [examples per class]
// Each bundle exports links(text) and linksCross(text): [name, href|null][] for every PR and commit name, resolved by
// refHref in a home session (org-a/project-a) and in one that claims a run elsewhere (rule 3 never opens home there).
import { pathToFileURL } from 'node:url';
const [tipPath, basePath, seedArg, countArg, samplesArg] = process.argv.slice(2);
const tip = await import(pathToFileURL(tipPath).href);
const base = await import(pathToFileURL(basePath).href);
const seed = Number(seedArg ?? 1);
const count = Number(countArg ?? 20000);
const samples = Number(samplesArg ?? 3);

let s = seed >>> 0 || 1;
const rnd = () => { s ^= s << 13; s >>>= 0; s ^= s >>> 17; s ^= s << 5; s >>>= 0; return s / 4294967296; };
const pick = (a) => a[Math.floor(rnd() * a.length)];
const many = (f, lo, hi) => Array.from({ length: lo + Math.floor(rnd() * (hi - lo + 1)) }, f);

const HOME = 'org-a/project-a';
const repos = ['owner-b/repo-b', 'owner-c/repo-c', HOME, 'Owner-B/Repo-B', 'src/lib', 'a', 'owner-b/repo-b.', 'o/r.Then', 'o/r.12'];
const ghWord = ['gh', 'gh', 'gh', 'GH', 'Gh', 'gh.exe', 'GH.EXE'];
const groups = ['pr view', 'pr merge', 'pr list', 'pr comment', 'issue edit', 'issue view', 'pr checks', 'api', 'repo clone', 'run list'];
const nums = ['12', '12', '13', '#12', '40'];
const CONT = ['\\\n', '\\\r\n'];
/** A word with a continuation glued inside it at a random place (the shell joins the halves), or an even run (a line end). */
const split = (w) => {
  if (w.length < 2 || rnd() > 0.25) return w;
  const at = 1 + Math.floor(rnd() * (w.length - 1));
  return w.slice(0, at) + pick([...CONT, ...CONT, '\\\\\n', '\\\\\\\n']) + w.slice(at);
};
const repoFlag = () => split(pick([
  `-R ${pick(repos)}`, `--repo ${pick(repos)}`, `--repo=${pick(repos)}`, `-R=${pick(repos)}`, `-R${pick(repos)}`,
  `-sR ${pick(repos)}`, `-sdR ${pick(repos)}`, `-dR ${pick(repos)}`, `-wR ${pick(repos)}`, `'-R' ${pick(repos)}`,
  `-R \\\n${pick(repos)}`, '-R', `-R "${pick(repos)}"`, `-R '${pick(repos)}'${pick(CONT)}-x`,
]));
const otherFlag = () => split(pick([
  '-s', '-m', '-e', '-b', '-d', '-w', '--squash', '--web', '--json state', '-L5', '-XGET', '-X GET', '--title', '--body',
  `--title ${pick(['GH', 'gh', 'Gh', 'gh.exe', 'GH.EXE', '"GH"', 'fix', 'x\\\\'])}`, `--body "${pick(['--repo=', '-R ', 'see -R '])}${pick(repos)}"`,
  `--add-label ${pick(['bug', 'GH'])}`, '--list', '-q.title', '--jq .title', '-iXGET', '-f state=closed',
]));
const arg = () => {
  const r = rnd();
  if (r < 0.3) return repoFlag();
  if (r < 0.55) return otherFlag();
  if (r < 0.75) return pick(nums);
  if (r < 0.9) return split(`repos/${pick(repos)}/${pick(['pulls/12', 'pulls/13', 'commits/1234567abc', 'commits/1234567ABC', 'pulls'])}`);
  return pick(['now', 'then', 'and', pick(repos), '12', '\\']);
};
const sep = () => pick([' ', ' ', ' ', ' \\\n', ' \\\r\n', '\n', ' \\\\\n']);
const command = () => [pick(ghWord), pick(groups), ...many(arg, 0, 5)].map((w, i) => (i === 0 ? w : sep() + w)).join('');
const sources = () => pick([
  `${pick(repos)}#${pick(['12', '13'])}`, `https://github.com/${pick(repos)}/pull/${pick(['12', '13'])}`,
  `https://github.com/${pick(repos)}/commit/1234567abc`, `cp -R ${pick(repos)} /x`, 'chmod -R 755 dist', 'GH_REPO=owner-b/repo-b',
  `GH_REPO: ${pick(repos)}`, `/repos/${pick(repos)}/pulls`, `-R ${pick(repos)}.-R=${pick(repos)}`, 'GH_TOKEN=x cp -R a b',
]);
const bare = () => pick(['#12', '#13', '#40', '1234567abc', '1234567a', '#12 is merged', 'fixed in #12']);
const joiner = () => pick(['; ', '\n', ', then ', ' and ', '\r\n', '\n\n']);
const message = () => {
  const parts = many(() => { const r = rnd(); return r < 0.5 ? command() : r < 0.75 ? sources() : bare(); }, 1, 5);
  parts.push(bare());
  let text = parts.map((p, i) => (i === 0 ? p : joiner() + p)).join('');
  if (rnd() < 0.15) text = '```\n' + text + '\n```\n' + bare();
  if (rnd() < 0.1) text = '`' + text.replace(/\n/g, ' ') + '`';
  return text;
};

/** The message as the shell reads it: each unescaped backslash-newline (an odd run of backslashes before it) deleted. */
const shellJoined = (text) => text.replace(/(\\+)(\r?\n)/g, (m, run, nl) => (run.length % 2 === 1 ? run.slice(1) : m));
/** Whether `slug` (owner/repo) stands as a token of `text`, in any case. */
const tokenOf = (text, slug) => {
  const esc = slug.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  return new RegExp(`(?<![\\w.-])${esc}(?![\\w-]|\\.\\w)`, 'i').test(text);
};
const slugOf = (href) => href.replace(/^https:\/\/github\.com\//, '').split('/').slice(0, 2).join('/');
const kind = (href) => (href === null ? 'text' : slugOf(href).toLowerCase() === HOME ? 'home' : 'other');

const classes = new Map();
const note = (cls, text, b, t) => {
  const c = classes.get(cls) ?? { n: 0, ex: [] };
  c.n += 1;
  if (c.ex.length < samples) c.ex.push({ text, base: b, tip: t });
  classes.set(cls, c);
};
let names = 0;
let changedMessages = 0;
let withContinuation = 0;
for (let k = 0; k < count; k += 1) {
  const text = message();
  if (/\\\r?\n/.test(text)) withContinuation += 1;
  const b = base.links(text);
  const t = tip.links(text);
  if (b.length !== t.length) { note('name count differs', text, b, t); continue; }
  let diff = false;
  for (let i = 0; i < b.length; i += 1) {
    names += 1;
    const hb = b[i][1];
    const ht = t[i][1];
    if (hb === ht) continue;
    diff = true;
    const kb = kind(hb);
    const kt = kind(ht);
    let cls = `${kb} -> ${kt}`;
    if (kt === 'home') cls += tip.linksCross(text)[i][1] === ht ? ' (attributed)' : ' (FALLBACK HOME)';
    if (kt !== 'text') {
      const joined = shellJoined(text);
      cls += tokenOf(joined, slugOf(ht)) ? ' [a token of the shell-joined message]'
        : tokenOf(joined.replace(/['"]/g, ''), slugOf(ht)) ? ' [a token once the shell removes its quotes]' : ' [NOT A TOKEN]';
    }
    note(cls, text, [b[i][0], hb], [t[i][0], ht]);
  }
  if (diff) changedMessages += 1;
}
console.log(JSON.stringify({ seed, messages: count, withContinuation, names, changedMessages,
  classesInNames: Object.fromEntries([...classes].map(([k, v]) => [k, v.n])) }));
for (const [k, v] of classes) {
  console.log(`\n== ${k} (${v.n})`);
  for (const e of v.ex) console.log(JSON.stringify(e));
}
```
