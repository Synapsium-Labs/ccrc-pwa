# The test box op: the read and the sync take the box token, and the sync's op word has no dot

Two departures TB9 of the test box plan (`docs/superpowers/plans/2026-10-29-test-box.md`, D-7411) found while building the
`testbox` agent op, the server's status and the switch route. Both numbers were issued by the ledger on 2026-10-30.

- **D-7554 (2026-10-30)** — `testbox-routes-box-token`: the plan has each of the three test box routes "session-authenticated as the other settings routes are", and in the same task gives `ccd/ccrc-api` the rows `testbox.status` and `testbox.tools-sync` "for TB11's update-lane call and TB13". `ccrc-api` is a cookieless fleet-host caller that sends the box token, and with the auth gate armed a route that is not in `server/src/auth/gate.ts`'s `EXEMPT` table is refused before its handler runs, so session-only routes would have made both rows dead on an armed server. Ruled: `GET /api/testbox` and `POST /api/testbox/tools-sync` follow `GET /api/runs`'s pattern (D-149), EXEMPT-BUT-AUTHENTICATED: each handler requires a live session OR a valid box token before it answers anything. Neither writes a registry file, and the sync takes no body and sends the box only the fleet host's own release and measured versions, so the box token buys nothing a session could not. `POST /api/testbox/switch` stays session-only (`coord-pause-route.test.ts`'s `SESSION_ONLY`) and has no `ccrc-api` row: arming remote runs is the operator's act. `server/test/testbox-routes.test.ts` holds all three, armed and dark.
- **D-7555 (2026-10-30)** — `testbox-tools-sync-op-word`: the plan spells the second op `testbox.tools-sync`. An op an agent answers is listed in its `ready.ops`, whose words follow `CAP_WORD` (`^[a-z][a-z0-9-]{0,31}$`, `shared/api.ts`), and the server's one reader (`readReadyOps`, `server/src/remote/client.ts`) reads a list holding any word off that grammar as `[]`. A dotted word would therefore make every server, an older one included, drop the agent's whole list, the `update`, `token-sync`, `account`, `disk` and `pressure` ops with it. Ruled: the op's word is `testbox-tools-sync` (`TESTBOX_TOOLS_SYNC_OP` in `shared/agent-protocol.ts`), the `req` member is `TestboxToolsSyncReq` with `op: 'testbox-tools-sync'`, and `ready.ops` grows from 5 to 7 words, every one on `CAP_WORD`. The `ccrc-api` row keeps its own `group.verb` name, `testbox.tools-sync`, which is that table's grammar, not an op word. `agent/test/testbox-op.test.ts` holds every word of the ready frame's list on `CAP_WORD`.
