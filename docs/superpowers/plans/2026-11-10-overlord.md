built. Two more W1a pieces run in their own runs, in parallel, and are not planned here: **#2726** (peer mail: an
invited reply is never refused by the peer bound) and **the Overlord's `MAIL_PACE` row** (totality over `FLEET_ROLES`,

decider joins `MUTANT_SETS` and `server/test/sim/mutation-floors.json` in the PR that creates it, so "mutation floors for
new deciders" is a rule of each plan, not a piece of its own.

*Table W1a-M. The machine pieces and their lanes.*

**One word (slug `generation-means-one-life`).** "Generation" means one life of a long-lived identity from start to
start, as the spec uses it (`continuity_generations`, `GenerationState`, `generationStep`). A registry row's life is its
**incarnation** in every new name and sentence (the start report's `rowIncarnation`, the generation row's
`rowIncarnation`); the tree's existing identifiers (`CCRC_SESSION_GENERATION`, `_reg_generation_read`,
`_reg_generation_valid`) keep their names. `ccrc history`'s "epoch" (a conversation) stays history's word. The spec
asks the plan to pick one word before W1a (§3.3.1); this is the pick.

**First, the two everything needs.** The renewal deciders (`roleFactsOf`, the vocabulary in `shared/continuity.ts`, the
deciders, `hardCapTokens`) and the start report (the routes file, the store module and the first table under
`server/src/continuity/`). They touch disjoint files and run at once.

**Then five lanes, one builder each, in parallel.** A lane's pieces run in the order the table lists them.
- **Lane A, ccd and the launch:** fresh start → launch profiles (PR A once renewal deciders PR A has merged, then
  PR B) → compaction. Its files: `ccd/ccd`, `server/src/ccdargv.ts`, `server/src/registry.ts`'s route read, the route
  region of `shared/api.ts` (`ROUTE_WRITABLE_FIELDS`, `parseRouteFields`), `ccd/lib/launch-profiles.json`,
  `ccd/ccrc-doctor-checks`, `shared/switches.ts`, the `launchProfile` and `compactInstructions` columns, and
  `server/src/continuity/{launchProfile,profileFor,profileLane,compaction,precompact}.ts`.
- **Lane B, the hook and the readings:** context readings → anchor. Its files: `ccd/statusline-command.sh`,
  `server/src/usage.ts`, `SessionUsage` in `shared/api.ts`, `server/src/continuity/{compactions,anchor}.ts`, and the
  hook's `_hook_compact_pre_line` (the bounded, dot-free events file `$REG/<id>.compactevents`, rotated at 32 lines to
  `$REG/<id>.compacteventsprev`, each line carrying the hook's scope verdict, under `.<id>.compactions.lock`; the
  PostCompact journal takes no new line shape, per ask 367) and its anchor slot. The
