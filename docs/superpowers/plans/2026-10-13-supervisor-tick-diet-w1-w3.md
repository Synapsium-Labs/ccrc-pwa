## Review Focus (the failure modes most likely to bite)

1. **A fast path answers outside its domain.**
   - Inputs: a NUL after a lead byte; invalid UTF-8; non-ASCII elsewhere in a limits file; a directory, FIFO, mode-000 file or symlink at a field path; a key and its value on separate lines; a value with trailing `\n\n` or a CR.
   - Expected: byte-equal stdout and equal rc against the vendored legacy, under `C` and under the UTF-8 locale.
   - Pinned by Task 2's corpus and Tasks 8 and 13's rows.
2. **An out-var collides, or `BASH_REMATCH` is clobbered.**
   - Inputs: a caller variable named like the callee's locals (`v`, `f`, `val`, `ts`); a caller that reads `BASH_REMATCH` after a converted call.
   - Pinned by the out-var census (Task 2) and the `BASH_REMATCH` audit in each wave's entry task.
3. **A stub is silently bypassed.** A converted site no longer calls the function a test stubs, and the test passes without exercising anything.
   - Pinned by the per-site stub census (Tasks 14 and 15), and by measuring each ported stub as load-bearing: red without the port, green with it.
4. **A crash under `set -u` on a new path,** which would take every supervisor after the sweep.
   - Pinned by the real-loop budget harness under `set -u` across eight fixtures, by `ccrc update`'s stay-up check, and by one wave per deploy.
5. **A line moves under the frozen corpus, or a census sentence goes stale.**
   - Pinned by the line-neutrality rule, `session-hook.test.ts`'s passes, `ccd-reg-get-census.test.ts`, and the untouched `ccd-tmux-anchor.test.ts`.
6. **A hang.** `_reg_read_to`'s `-L` then `-f` order must stay ahead of the open, or a FIFO or a link to `/dev/zero` blocks a supervisor forever.
   - Pinned by the FIFO and symlink rows, bounded by an outer `timeout`.
7. **A memo outlives its call.** `_share_pct`'s memo must die with the `_swap_target` call that made it, and `_cfg_dir_to`'s must answer per wrapper.
   - Pinned by Task 10's and Task 5's rows.

_limit_text_to() {   # var file -> rc 0: var = the file's text, INSIDE the stated domain | 3: outside it (the caller runs the pipeline)
  local LC_ALL=C __lt_t='' __lt_ran='' __lt_rc __lt_ws=$' \t\n\v\f\r'
  printf -v "$1" '%s' ''
  [[ -f "$2" && -r "$2" ]] || return 3
  { __lt_ran=1; IFS= read -r -d '' -n 65536 __lt_t; } 2>/dev/null < "$2"; __lt_rc=$?
  [[ -n "$__lt_ran" ]] && (( __lt_rc == 1 )) || return 3     # open failed, a NUL, or the 64 KiB cap reached
  [[ "$__lt_t" == *[!"$__lt_ws"!-~]* ]] && return 3            # a byte that is not printable ASCII or \t\n\v\f\r
  printf -v "$1" '%s' "$__lt_t"; return 0
}
_limit_num_in_to() {   # var text key -> rc 0: var = the FIRST match's digits in file order | 1: none (var empty)
  local LC_ALL=C __ln_c=$'[ \t\v\f\r]*' __ln_re                # literal bytes: a match never crosses a newline, as grep's per-line match cannot
