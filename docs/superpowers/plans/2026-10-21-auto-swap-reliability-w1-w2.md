## Review focus (the failure modes most likely to bite)

1. **A rescue or a leave delayed or refused, or a busy session stopped.** Nothing new runs on the hard-blocked path before `_dispatch_swap … rescue` except D-6180's note on the silent exits that already return; the guards, the pin and the markers are never read when `hard_blocked` is set, and the guards are never read for a ceiling-leave (`cur_serves` false). No new `CCD_SWAP_ARM` value: a new cause rides `CCD_SWAP_WHY`, so `cmd_swap`'s act-time `case` stays byte-identical. A diff that moves any read above the rescue dispatch, adds a `return` on it, or adds an arm word, is refused.
2. **A herd.** Every new automatic move goes through both slots and `_swap_idle_gate`; the slots are a sliding test under the lock (two grants onto one account never closer than `HOME_RETURN_SPACING`, fleet-wide never closer than `AFFINITY_FLEET_SPACING`); legacy pins expire relative to the first tick that reads them plus a hashed offset, never their mtime; the guards fail open.
3. **An unmeasured read that moves a session.** D-6182 reads "ended" only from a present figure whose `ResetAt` has passed (a missing file, field or clock answers "not ended"). D-6184 takes only a candidate with both windows measured and class gate rc 0. D-6183 falls back to today's ranking when `CCRC_ANTHROPIC_BACKEND` is not declared.
4. **A pool crossed.** D-6184's candidate passes the same `_pool_ok` and crossing rule as the loop, through one shared predicate.
5. **A decision changed outside the ruled rows.** Each behaviour commit flips only its named "today:" rows; the swap path's refusal set, `_swap_idle_gate`'s verdict table, `_limit_score`, `_avail` and `_rescue_policy` are byte-identical.
6. **The tick slowed.** No fork on the steady-state tick; the evidence probe runs only on a limit-arm silent exit, its answer (`none` included) cached for `TRANSCRIPT_ARM_INTERVAL`.
7. **A log that floods or lies.** One line per episode and a re-log floor; the episode is not cleared by `_tick_decided`; a limit-arm stand-down with no evidence writes nothing; the probe never writes a `carried-in` line; `lane=` names the target's backend through `_is_anthropic_backend`, never a second list; `auto-sideways` comes only from rc 7.
8. **A marker that does not switch it off.** Each marker's "present → today's answer" pin; the marker is read on the tick, not cached across ticks.
9. **A pin dropped by a reader.** `swappin` stays one word; every reader of the old format, a revert and a mixed-version deploy keep holding new pins.
