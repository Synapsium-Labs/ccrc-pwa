## What was built

- **One forbidden-program extension.** `pmatch` sits beside `fmatch`, not in another guard. All three modes read it:
  `deny` for children, `account` for other sessions, and `class` for classifier parity and MCP strings. Both prefilters
  gain `*prune*`. The hook is tested on child and top-level sessions, each on its main thread and in a subagent, using
  fixture HOMEs only. An already-set deny is never replaced.
- **Reason and advice.** They name `git -C <main> worktree remove <path>`. The hook also names the dry run and the file
  workaround (`git commit -F <file>`, `gh pr create --body-file <file>`). `ccd/ccd`'s four old advice sites belong to R1.
- **Authority is the plain refusal.** Raw and quote-stripped readings decide first. The bounded quote reader may relax
  a refusal only with a complete, modeled text-only reading: every prune mention must be quoted text or in a completely
  read quoted heredoc body. This is deliberately not a shell parser and does not claim to read everything as bash does.
- **Unsupported syntax retains that refusal.** An unquoted word-start `#`; words between a shell and `-c`, or anything
  after `-c` other than one quoted string; indirect heredoc-to-shell routing (later-line pipes, continuations, grouped
  pipes, `source` or `.` of stdin); complex substitutions/backticks inside double quotes holding parentheses or a single
  quote; CRLF; and multiple heredoc operators on one line all prevent a text-only exception.
- **Modeled text.** A heredoc operator must stand in code. Its whole delimiter word is read, quotes removed. Quoted
  bodies are text; unquoted bodies retain live substitutions but consume escaped backticks and escaped dollars first.
  A shell or `ssh` anywhere on the operator's own line keeps its body as code. Unreadable delimiters, unclosed bodies
  and more than 16 operator lines fail closed. Direct quoted shell `-c` strings are read one level deep.
- **Operands and dry runs.** Git global options and assignments accept complete substitution/backtick operands holding
  spaces. Only the words after the matched `prune` supply dry-run flags. Their last `-n`, `--dry-run` or unique
  `--no-d…` negation decides. The tail is cut only at `#`; any dollar, redirection or backtick in it voids the exemption.
  Thus `git worktree prune -n > out` is refused too, rather than hiding a later negation behind a cut.
- **Classifier parity.** `FORBIDDEN_PATTERNS` delegates its prune row to the same decision shape. Fixtures contain
  123 must-deny and 43 must-allow strings. The actual embedded jq answers the prune category in deny mode and agrees
  with the classifier in class mode. Three inline own-body shapes are checked on the prune reason, not on an unrelated
  account refusal. These payloads are JSON command text, never commands executed by the suite.

## Residuals

An accident guard, never a security wall. These remain outside the bounded reading:

- Assembled strings, scripts, aliases, shell functions and `eval`.
- A `$VAR` program, such as `G=git; $G worktree prune`; no new `xmatch` row.
- `git gc` and automatic gc can prune records past `gc.worktreePruneExpire`; R1 recovers archived rows independently.
- Unnamed wrappers/options, including `sudo -u`, `timeout -s`, `env -u`, `exec -a`, `xargs` and `find -exec`.
- A redirection before the program, or a `case` arm after `)`.
- More than eight global options or four wrappers.
- Dollar-quoted splits of prune at the prefilter, and quote-split prune in a top-level payload over its 8 KiB strip cap.
- B6: literal strings fed to a shell by a here-string, `echo … |` or process substitution.
- B9: empty or runtime-decoded spellings, `coproc` and `watch`.
- B10: `ssh host '…'`.
- B4: nested shell `-c` strings beyond the one modeled level.
- FD5: quoted prose within a substitution inside double quotes.
- Main's whole forbidden-program `norm` passes are quadratic on crafted quote-dense input, as measured above.
- The operator's own shell has no hook.

Accepted false denies, in the safe direction:

- FD2: comments containing prune syntax; an unquoted word-start `#` prevents a text-only exception.
- FD4: more than one heredoc operator on a line.
- FD6: CRLF line endings.
- Unsupported shell `-c`, indirect heredoc routes and complex quoted substitutions retain the plain refusal.
- `--help`, `-h`, bundled/abbreviated dry runs (`-nv`, `-vn`, `--dry`), and any dollar, redirection or backtick in the tail.
- Unreadable/unclosed heredocs or more than 16 operator lines, and a shell or `ssh` anywhere on an operator line.
- Class-mode MCP strings may classify a prune mention as forbidden and make it unroutable for approval.

## Departures, by slug

- **`pmatch-beside-fmatch`.** `fmatch` also runs after quote-stripping `norm`; putting this row there would undo the
  bounded quoted-text exception. It stays in the one existing program, asked in each mode.
- **`quote-aware-reading`.** FR1's unrestricted quote-aware authority is superseded by FR2's complete-proof exception
  to the plain refusal. Unsupported shapes never authorize an allow.
- **`dry-run-cut-at-redirections`.** The old departure was unsafe: cutting could hide a later negation, not merely
  refuse more. Superseded by a tail cut only at `#`, with dollars, redirections and backticks invalidating exemption.
- **`heredoc-fails-closed`.** Complete delimiters and bodies, bounded operator lines and unsupported routing checks.
- **`dry-run-voided-by-any-dollar`.** Retained and extended to redirections/backticks; unique negations cancel too.
- **`worktree-anchor`.** Segment-first worktree/prune candidate rejection is a cost gate, not another authority.
- **`own-pr-body-checked-on-the-row`.** Three inline shapes checked only for the prune reason; an inherited account
  refusal on unrelated body text is not claimed fixed.
- **`timing-pin-is-a-ratio`.** Now actual historical/current whole programs and single-event startup, with scaling.
- **`jq-startup-cost-accepted`.** Coordinator accepts fixed 4–6 ms startup cost and the `max(1.5x, +25 ms)` budget;
  inherited ratios above 2.5 use historical plus the explicitly accepted 0.5 margin.
- **`command-position-and-wrappers`.** A bounded program-position grammar, not a search for every prose mention.
- **`more-global-options`.** Extra flag/value options beyond the plan's six each have must-deny evidence.
- **`fixtures-are-string-lists`.** JSON arrays of Bash command text; tests do not execute their contents.
- **`five-hook-suites`.** The four named deny suites plus `session-hook.test.ts`.
- **`ccd-advice-left-for-r1`.** R3 changes wsaudit advice only; all four ccd sites stay with R1.
