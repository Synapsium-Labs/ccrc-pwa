Every assertion that protected the decision (the `PROVIDERS`/`openrouter` bans, "imports nothing", "declared in exactly one file", the loopback-set scan) must now read `shared/base-url.mjs`, and each must have a mutant that edits the `.mjs` and reds it. Reviewers ask of every re-pointed row what edit to the `.mjs` would red it.
2. **A tautology that passes.** "The twin answers identically" compares a function with itself after K2. K2 replaces it with an identity assertion (the `.ts` import and the `.mjs` import are the same function object, `toBe`), which reds if anyone re-adds a local copy in the `.ts`.
3. **A type union moved out of sight.** `rings/wire-totality.test.ts` scans `shared/*.ts` only. Moving `BaseUrlRefusal` into `shared/base-url.d.mts` would make its exemption stale (red) and, if the exemption were then deleted, would shrink `EXEMPT_PINNED` by hiding a listless union rather than giving it a list. D-7307 keeps the types in the `.ts`, and K2's mutant table proves the scan still sees them.
4. **A specifier that changed.** Ten import sites keep their specifiers byte for byte (item 2). A caller re-pointed from `./base-url.js` to `./base-url.mjs` (or back) changes nothing at runtime and everything for the next reader. K2's Exit lists the importers at base and tip, and they are equal.
5. **A stored value that moved** (K3). Under (a), `parseRegistry` takes `BASE_URL_OK`'s **verdict** and keeps storing the text it was given. Storing the gate's `url` instead would rewrite 5 of the 9 accepted rows (item 5) and every `models-op` pin that reads `https://api.cortecs.ai` back. That is option (b), not the recommendation.
6. **A mutant counted against a row that cannot red** (rev 1). A REAL row that only reports cannot go red, and the existing roster-bash row reads `.ts` and `.tsx` only, with an ordered loopback regex (item 8). Every mutant in K1's table names a FIXTURE row or an exact characterization row of K1's own; reviewers check each red names one.
7. **A fixture tree without the `.mjs`** (K3). `models.mjs` gains an import, so any tree that copies it alone fails with `ERR_MODULE_NOT_FOUND`, not a lint warning (`installTreeFixture.ts`'s own comment on D-2599 records 120 tests red that way). Step 0 re-measures every list.
