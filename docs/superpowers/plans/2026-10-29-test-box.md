## Review focus (the failure modes most likely to bite)

1. **Scratch refs reaching `origin`.** The wrapper refuses a mirror URL equal to any of the clone's own remotes, and every push names explicit `refs/ccrc-test/<run-id>/*` destinations. A row pushes with a fixture whose `CCRC_TESTBOX_GIT_URL_BASE` equals `origin`'s URL and asserts nothing was sent (TB3).
2. **The session's index or tree touched.** The snapshot works on a copy of the index with `GIT_OPTIONAL_LOCKS=0` for the clean check. Rows compare the session's index bytes, `git stash list`, the worktree listing and every file's mtime before and after (TB3).
3. **A fleet secret leaving.** The run's environment is built from empty plus the allowlist; the session environment is never forwarded; the deny list runs before the push. TB4's runner row and TB8's env row print every name a fixture run sees.
4. **The fleet agent widened.** The `testbox` op adds no whitelist entry, no wire-supplied argv and no file read beyond the token file the settings name; its spawns are the fixed templates of D-7430. The service's systemd adapter lives under `agent/src/testbox/` and is imported by nothing the fleet agent's entry point loads; an import census reds the edge (TB4).
5. **A remote answer that differs from local.** The worker count, `TMPDIR` length, `CI`, the build outputs, the branch and `origin/main` each have a fixture row in TB3, TB4 or TB8; the parity check (TB14) is the last word.
6. **Carry-over.** Every run gets a fresh directory and a fresh checkout; the cleanup is a root unit outside the run's sandbox. The carry-over fixture (spec §2.3) runs in Part A against the seams and in Part B against real units (D-7431).
7. **A switch that is not off.** TB0's pins; and the marker has one reader in shell (the wrapper) and one writer (`ccd testbox-remote`), held by a single-definition row (TB2, TB9).
8. **The release or a tool installed unverified.** TB6 copies `_upd_fetch`'s verification order and exit reading exactly; a fixture bundle naming another workflow, an absent bundle and a mismatched checksum each leave `current` and the installed release unchanged.
9. **A refused run read as red.** Exit 75 only from an explicit `--remote` budget refusal, `CCRC_TESTBOX_FALLBACK_INSTALL=refuse` and `CCRC_TESTBOX_LOST_RUN=fail` before anything ran; every fallback exits with the local run's status (TB8).
