## Global constraints

Every task's requirements include this section. `CLAUDE.md` is the authority; this is its working subset.

- **Public repository.** Every line, fixture, screenshot, commit message and PR body is public. Fixtures and screenshots use neutral names (`project-a`, `lane-a`). No hostnames, account or lane names, absolute home paths or people's names. `server/test/topology-clean.test.ts` stays green.
- **No root runner.** Run cd'd into a package: `cd pwa && ./node_modules/.bin/vitest run test/<file>`; `cd server && ./node_modules/.bin/vitest run test/<file>`. **Never bare `npx vitest`.** `cd ui && npm ci` before `cd pwa && npm ci`. Suites run in the FOREGROUND with a timeout of at least 600000 ms. A `CLAUDE.md` load flake is re-run alone before it is called a break.
- **The palette is generated.** A value inside `tokens.css`'s `GENERATED THEMES` block is never hand-edited. Change the seed or the derivation in `ui/design/make-themes.mjs`, run `cd ui && npm run themes`, and commit both. `npm run themes:check` and `pwa/test/theme-catalogue.test.ts` refuse drift.
- **The bridge maps, it never defines.** A new token is declared in `tokens.css`'s `:root`, with a light override if it is colour, then mapped in `theme.css`'s `@theme inline`. Check the name against Tailwind v4's namespaces first (`--text-*`, `--font-*`, `--leading-*`, `--tracking-*`, `--shadow-*`, `--ease-*`; `ui/README.md`, "Adding a token"). `theme-bridge.test.ts` and `css-vars.test.ts` hold the seam.
- **A new ui primitive is classified in `role-census.test.ts` in the task that adds it, once Task 14 has merged.** Before Task 14 merges, the new primitives (Task 5's `meter.tsx`, Task 8's `icon.tsx`, Task 10's `command-palette.tsx`) are classified by Task 14 itself, which therefore lands after them.
- **A skin owns no colour.** `skins.css` declares only `SKIN_TOKENS` members, with no colour literal, and motion only under `prefers-reduced-motion: no-preference` (spec §3.2). From Task 2 on, `skin-identity.test.ts` enforces this.
- **Both skins, every width, every PR** (spec §9). The PR body carries the matrix:
  - skins: Refined and Instrument;
  - widths: 360, 390 and 438; 1280 and 1440 or 1470; 1920;
  - modes: Phosphor & Ink and Phosphor Daylight, plus Dracula and GitHub Light when the PR changes palette values.
  - Each cell is marked ✓ or carries a note. Primitives are checked in Storybook, screens in the app against a fixture home (spec §9). A desktop-only interim is not acceptable.
- **Mutation discipline.** Every guard ships with a test that goes RED when the guard is deleted, AND when it is made wrong. Each task's mutation table is RUN, never read: apply the mutant, run the named suite alone, record the red line, then restore with `git checkout -- <file>`. Never commit a mutant. "A comment is a request; a red suite is a mechanism."
- **The boundary tests.** A class emitted by a `@ccrc/ui` cva joins `design-system-boundary.test.ts`'s OWNED list in the task that adds it. An app sheet may PLACE a ui component but never REDRESS one (`ui-package-boundary.test.ts`). A hook class handed to a ui component names nothing else (`hook-class-collision.test.ts`).
- **No new dependency.** No task edits a `package.json` or a lockfile (spec §12 O5). The fonts and icons are vendored with their licences.
- **Deviation ledger.** Numbers are ISSUED by `POST /api/ledger/deviations`, never chosen. This plan defines D-5093 to D-5104 (§Deviations found), and later plans cite them. No tracked file carries a concrete placeholder of the form `D-TBD-<slug>` (`dtbd.test.ts`).
- **Branch discipline.** One commit per task on the workspace's own branch, never a separate feature branch. Absorb `main` only with `git merge`. Every commit leaves the suites it touches green.
- **SAFETY.** Nothing here runs ccd, touches tmux or a live fleet, or reads a live pane. The visual check's local server runs against a fixture `CCRC_HOME` **and** `HOME`, on a machine that runs no fleet (spec §9, README "Run the server against a fixture home").

## Review focus (the failure modes most likely to bite)

1. **Colour leaking into the skin channel.** Any colour in `skins.css` makes the contrast gate's per-palette verdict false for one skin. Task 2's guard is the wall. Review that every Instrument value is a scale step, a length, `none`, or an elevation recipe on `var(--edge-*)`.
2. **Reduced motion undone by specificity.** `:root[data-skin='instrument']` (0,2,0) beats `:root`'s reduced-motion block (0,1,0). A `--dur-*` override outside `@media (prefers-reduced-motion: no-preference)` silently re-animates everything.
3. **A frozen file edited "just a little".** See §In flight. A red `contrast.test.ts` census is a STOP, never an edit.
4. **The generator lane colliding.** Tasks 4, 6 and 9 each regenerate the same block. Merge them in order and re-run `themes` after each `git merge`.
5. **Escape reaching through the palette.** Task 10's Escape must close the palette and never interrupt a busy turn.
6. **Storage that throws.** Private windows, previews and thumbnail capture throw on `localStorage`. The skin must still apply.
7. **Hover that sticks on touch.** Hover is only ever Tailwind's `hover:` variant, which v4 gates on `(hover: hover)`, or an app rule inside `@media (hover: hover)`.
8. **A class eaten by the merge.** `cn()` is tailwind-merge, which places an unknown utility by its prefix. Every new size key and spacing key must be taught to `cn.ts` (Task 1), or `text-meta` silently deletes the ink beside it.
9. **Role adoption that moves a pixel in Refined.** Task 14 changes class names, not looks: every role's Refined value equals the step it replaces, or the class stays a scale step on the census's allowlist with a reason.
10. **"Unmeasured" read as "clean".** The divergence frame has no cold start. "No frame yet" is never rendered as an all-clear (Task 15).
