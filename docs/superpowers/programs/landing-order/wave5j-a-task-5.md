  `sessionAuth(req)` whose `reason` is `session` passes, and otherwise `checkMailToken(…, 'GET /api/landing')` must answer

  dark the check does not run. Query, answer and every other refusal are unchanged; the answer carries `order.waits`
  when present. The JSDoc above the route, which said "box token", now says what the read takes (C4).

  5j-a, D-9048), the same dual-credential arrangement as` `GET /api/feed`, and says `ccrc-api landing show` reads
  cookieless and the console with a session. The header's reason-2 list names `/api/landing`, with no number word. No
  route count moves: the read was exempt before and stays exempt.

- `CLAUDE.md` blocks 1 and 2 and README blocks R1 to R3, byte for byte as section 9 gives them. Each old block occurred
  exactly once on the dispatch base and on `main` at `cb973d690c`, and each new block occurs exactly once on this tip.
