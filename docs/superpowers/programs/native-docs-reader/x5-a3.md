# Task X5 A3: the wrapper, the content door and the budgets

The task note for native Docs reader wave 56 (X5 wave A3, run 4032). It is what the ledger should learn from this wave. The design is `docs/superpowers/specs/2026-11-19-native-docs-html-artifacts-design.md`, and its leaf plan is `docs/superpowers/plans/2026-11-19-native-docs-html-artifacts.md`. That plan's Results section, "Wave A3", gives what was measured and every mutation row.

## In short

- **What landed.** A link the console mints now opens a page:
  - `GET /a/<token>` on the artifact host answers the wrapper: a script-free page with ccrc's own bar ("This is not ccrc") and one sandboxed frame;
  - `GET /c/<token>/<path>` on the content host serves only the files the mint recorded, at the pinned version, under the page's CSP and the fetch fences, with ranges, a 1 GiB-an-hour budget counted by what is served, 4 requests in flight per link and 16 per box (a request waits up to 90 s, never refused at once), the stall and whole-response deadlines, and every link's end reaching work already under way;
  - `GET /clear` clears the content host's storage, from the wrapper's own frame only.

  Nothing changed on the console's screens (wave A5). No door was added to the console's instance (the gate's counts stay 341, 338, 220 and 118), and no migration, box token, exempt class, `ccd` verb or agent grant was added.
- **The first items.** The record from the last review of A2 (the dead session's 401 is the session gate's; row A2-FR1-3a names the account gate's suite); the console and the artifact instance no longer echo the request path in Fastify's early 400 and 414; a chunk-extension overflow answers 413; no answer is written into a response already under way.
- **Deviations.** D-9145 (content responses vary by `Sec-Fetch-Dest` and `Service-Worker`, and scripts are never cached, so a browser's cache cannot stand in for the service-worker fence), D-9146 (an artifact range prepare does not take the lane's artifact share, so a page's second large file prepares while its first streams) and D-9147 (six places where the code departs from the plan's written Interfaces). D-8787 is carried out: the completion plan's walls sentences are amended. D-9145 and D-9146 came from the wave's reserve; D-9147 was issued beyond it. None is returned. Fix round 1 (review 4050) adds D-9149 (every type a browser opens as a document that can run script, HTML, XHTML, SVG and every XML type, is never cached, as HTML is) and a seventh place to D-9147 (the store's `charge` answers an ended capability as `dead`, apart from a spent hour).
- **Not right yet.** While an artifact page prepares a large file for the first time, the console opening a large file of its own may be told the reader is busy, for up to about half a minute. Follow-up `x5-fu-console-prepare-waits`, in the plan's X5 epic.

## Choices made in the wave, for the ledger

| Choice | Why |
|---|---|
| The content door's engine in its own L4 file, `server/src/artifacts/content.ts`, with no Fastify import | The queue, the deadlines and the frame writing sit outside the Fastify allow list; `routes.ts` implements a small reply interface (D-9147) |
| Every decision of the door in L1 (`server/src/artifacts/policy.ts`) | Decide in L1, act in L4: the raw path, the hosts, the fence's input, the header set, the status, the prepare slot, what a failed read becomes |
| The bytes adapter a closure in `server/src/docs/routes.ts`, its decisions L1 helpers in `server/src/docs/policy.ts` | D-9136's rule: the adapter books the console's own docs lane; `ccdsource.ts` (L3) books nothing |
| The adapter neither probes nor fills the docs blob cache | A listing cached for a commit could name another blob than the manifest's pin |
| Each route answers only on its own host (design 3.4's table) | A page's file served on the artifact host would run on the wrapper's origin |
| The hour's budget charged per frame written | A seeking video asks for the rest of a file on every seek; charging the asked length spent the hour in about 16 seeks |
| The prepare budget (one at a time, three a minute) with the door's 90 s wait, not in the lane | The lane's own wait is 10 s, shorter than the minute (D-9147) |
| The lane's source word `reader`, not `console` | The docs policy file's L1 scan refuses the word console in its code (D-9147) |
| `cacheKind` names the JavaScript types once, from the MIME Sniffing standard's list, and a case walks the MIME table | One place for "a browser runs this as a script" (D-9145) |
| A HEAD of a changed draft answers 200 | HEAD reads nothing, so it cannot see the change; a GET answers 409 |
| The console's early 400 and 414 answer Fastify's `error`, `code` and `statusCode` with no `message`; the 414's `error` is `URI Too Long`, its own runtime phrase (`frameworkErrorPhrase`, L1) | Fastify's default `message` echoes the request path, and a path misrouted from an artifact host holds a capability token; the first build said `Bad Request` for the 414 too, which review 4050 caught (fix round 1) |
| A bad count to the store's `charge` throws | The one caller passes a frame's length; a bad count is a programming error, and answering it `dead` or `over-budget` would hide it as an end or a spent hour (fix round 1, D-9147) |

## For later waves

- **Wave A5's browser proofs.** "A service worker cannot register" loads the script by a script tag first and then registers it with the cache allowed, and still fails (D-9145, not measured in a browser here).
- **The next server wave of this programme.** `x5-fu-console-prepare-waits`: a console range prepare waits out an artifact prepare instead of answering busy (D-9146's residual). Once a console prepare waits out an artifact prepare instead of answering busy, an artifact frame queued behind it outlives its own 10 s lane wait and is answered busy: a response under way is cut, one not yet started answers 503. So `x5-fu-console-prepare-waits` must also keep artifact jobs from waiting behind that prepare (or give them a longer wait), or it reopens D-9146. The lane's two fix-round cases show today's order (10000 against 11000 ms), on which this rests.
- **Carried by the coordinator, not this wave:** an artifact origin whose label has a secret's shape (it needs the site-rule table and the setup command's mirror).
