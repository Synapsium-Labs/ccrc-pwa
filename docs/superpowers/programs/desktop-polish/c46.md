# Task C46: the fleet list drops the subagent and delegated counts (D-8771)

The task note for desktop polish Task C46. The operator's words, 2026-11-19: "the number of subagents in a session is
noise at this point on the left panel. It's information useful only inside the session running them." Every claim below
is labelled **measured** or **inferred**. `main` is 6095bf43d; "here" is this task's branch.

## In short

- A session's row in the fleet list (the left panel on desktop, the session list on a phone) draws no count of the
  session's subagents or delegated entries. The session's own header and details keep every one of those facts, unchanged.
- The R9 chip (`N delegated`, D-7781) is gone from the card, and the field behind it with it: `CardFacts` has no
  `delegated`, so no dead fact survives. D-7782's count comparison in `cardWithinHeader` is gone with it: every card fact
  is now held by a prefix test against the header's fact under the same key.
- A coordinator's fold line and a programme box's footer named their delegation children as `n delegated` and
  `n worktrees`. That is a separate grouping the operator taps to open the delegated rows themselves, so the fold and its
  rows stay and only the numbers go: the line says `delegated` and `worktrees`, so a fold that holds only those rows still
  says what it holds. The footer still has a reason to show (its worker counts), so it stays, with the word and no number.
  The coordinator ruled this reading on 2026-11-19 (mail 25551).
- Nothing the header shows was lost (**measured**, below).
