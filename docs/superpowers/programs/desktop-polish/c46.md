# Task C46: the fleet list drops the subagent and delegated counts (D-8771)

The task note for desktop polish Task C46. The operator's words, 2026-11-19: "the number of subagents in a session is noise
at this point on the left panel. It's information useful only inside the session running them." Every claim below is
labelled **measured** (a command was run and its result seen) or **inferred** (read from the code or the ruling only).
`main` is 6095bf43d, this branch's merge base; "here" is this task's branch.

## In short

- A session's row in the fleet list (the left panel on desktop, the session list on a phone) draws no count of the
  session's subagents, delegated entries or delegated background work in its text, and none of the first two in its titles or
  accessible names. A working row's status TITLE is the one place a count stays: it keeps the background count (`2 in
  background: workflow, agent`), as the coordinator ruled in fix round 1 (**measured**: `card-header-facts.test.tsx` pins the
  card's text and title). The session's own header and details keep every one of those facts, unchanged (**measured**: the
  header and details tests pass, `SessionDetails` is untouched).
- The R9 chip (`N delegated`, D-7781) is gone from the card, and the field behind it with it: `CardFacts` has no
  `delegated`, so no dead fact survives. D-7782's count comparison is retired whole (it had only a card side), so the subset
  rule is a prefix test for every key again (D-5545), with one allowance, below (**measured**: the card's type has no such
  field and the compile check is green; **inferred** from reading `cardWithinHeader` that D-7782's comparison has no other
  caller).
- A working row's `working · N in background` (D-5231) counted the session's own delegated background work, the same class.
  On the card it reads `working · in background`; the count and the kinds are in its title (`2 in background: workflow,
  agent`), and the header keeps `working · 2 in background` (**measured**: `card-header-facts.test.tsx` and
  `session-line.test.tsx`). The coordinator ruled this in fix round 1 (mail 25635) (**inferred**: from the ruling mail).
- A coordinator's fold line and a programme box's footer named their delegation children as `n delegated` and
  `n worktrees`. That is a separate grouping the operator taps to open the delegated rows themselves, so the fold and its
  rows stay and only the numbers go: the line says `delegated` and `worktrees`. The footer still has a reason to show (its
  worker counts), so it stays, with the word and no number (**measured**: `fleet-rollup-render.test.tsx` W4-U31 and
  `rollup.test.ts` W4-U25). The coordinator ruled this reading on 2026-11-19 (mail 25551) (**inferred**: from the ruling mail).

## What stays in the list on purpose

- **The group headers' `(N)`** (`Offline coordinator (N)`, `Unowned work (N)`, the fleet foot's `Delegated work, session not
  listed (N)`) count the members of an orphaned, unowned or unlisted group, not one listed session's own entries, and none
  sits on a session row. They stay (the coordinator's ruling, fix round 1). **Inferred**: when every member of such a group
  comes from one gone session, the figure equals that session's count.
- **The design system's `WorkbenchSidebar`** (`ui/src/components/workbench-sidebar.tsx`) still draws a per-session subagent
  count and is exported from `@ccrc/ui`. Nothing in `pwa/src` mounts it (**measured**: grep), so no fleet list shows it today.
  If it is ever mounted as the fleet list it must drop that count. Out of scope here (the coordinator's ruling).
- **One wire doc comment** is left for the next holder of `shared/api.ts` (the coordinator's ruling: do not wait for the
  claim another run holds, and carry it). It is at `shared/api.ts:12729` on this branch's base, and reads: "An activity's own
  row under its parent, or a chip on its parent's row when the parent is a programme worker (R9)." The chip it names no longer
  exists; the sentence should say that a chip-placed activity is no row and is listed in its parent's details (**measured**
  that the sentence is there and says "a chip on its parent's row"; **inferred** that it misleads no reader, being a
  comment).
