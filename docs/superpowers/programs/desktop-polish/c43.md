## 2. The layout arm

A file ADDED or COPIED, or a rename's TARGET, under `docs/superpowers/specs/` must match
`^YYYY-MM-DD-<slug>-design(\.md|\.promise-ids\.json)$` and under `docs/superpowers/plans/` `^YYYY-MM-DD-<slug>\.md$`,
the slug `[a-z][a-z0-9]*(-[a-z0-9]+)*` of at most 40 characters, with nothing between the directory and the name. This
is the judge's rule for this repo's settings (specs in markdown, no slice files) (measured: read from the judge's
layout source, read-only). It holds on every branch, a `ledger/` branch included, and no `Ledger-Edit` trailer
passes it. A modification, a deletion and a rename's source are never a layout violation. The report lists each path
with the shape it should take, and for `plans/` points at the programs route. `--mode warn` reports and exits 0; the
exit stays 1 from load. The merge-queue and shallow-checkout skips cover both arms, as before.
